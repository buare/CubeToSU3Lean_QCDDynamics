# 玄空大卦與羅盤先天圓圖在立體易上的位置（2026-10-27）

**一句話**：大卦的兩個數字是立方體上的兩個座標；羅盤的先天圓圖是兩層八叉樹的 Z 序（分區遍歷），不是一筆畫。

**形式化**：`CubeToSU3/DaguaCube.lean`。只用 Lean 核心，不需要 Mathlib，可單獨編譯（約 1 分鐘）；已用 Lean 4.16.0（本 repo 的版本）與 4.19.0 編譯通過。47 條定理全部用 `decide` 證完（32768 種情形的線性檢查用 `decide +kernel`），只依賴 Lean 的標準公理 `propext` 與 `Quot.sound`，沒有 `sorry` 與 `native_decide`。各節對應的定理名見 §8。

> 本筆記原存於 claude.ai 專案「白話群論」。文中提到的 RULES_V2.md、QCD_GAP.md、SPDF_CUBE.md、WuxingBridge 在該專案裡，不在本 repo。§6 的腳本是同資料夾的 `dagua_v2_parity.py`。

## 1. 大卦的兩條公式

N = 先天卦配洛書數：坤1 巽2 離3 兌4 艮6 坎7 震8 乾9（錯卦相加為 10）。

- 卦數 = N（上卦）
- 卦運 = N（上卦 XOR 下卦），逐爻比較，不同記陽、相同記陰

與公開分運表（生活易經一起看〈論『玄空大卦』之基本功〉）逐卦比對，64 卦全部相符。注意：卦數看上卦，不是下卦。

代數上，大卦是 F₂⁶ 的一次換座標（剪切）T(上, 下) = (上, 上⊕下)，T² = 不動。這是同構，不只是商：只取卦運時是對對角子群 Δ = {(a,a)} 取商，得到 8 類；加上卦數才是完整的 64 卦。

**哪一半是唯一的、哪一半是選的**：卦運（對 Δ 的商）是唯一的。卦數這個「絕對座標」要挑一個和 Δ 互補的 3 維子空間；F₂⁶ 裡這樣的子空間有 2^(3×3) = 512 個（Python 窮舉 1395 個 3 維子空間驗證；Lean 證了「至少 512 個」）。「只變上卦」與「只變下卦」都是其中之一。大卦的卦數選了上卦，羅盤圓圖的分段選了下卦（§3），兩者都合法，只是選法不同。

## 2. 上下疊法下的幾何（上卦 = 大立方體 R，下卦 = 小立方體 r）

- 卦限（座標正負）= 上卦 → 卦數。
- 每軸 |座標| 是 R+r（上下同爻）或 |R−r|（異爻）→ 卦運。每個運的 8 卦是一個長方盒的頂點。
- 球殼：一運｜六七八運｜二三四運｜九運 = 8、24、24、8。「二三四運九為父母，六七八運一為父母」= 第三層貼最內層、第二層貼最外層。
- 卦數合十 = 換對面卦限；卦運合十 = 每軸內外互換。一配九、二配八、三配七、四配六。
- 上下同位爻一起變 = 鏡射，留在同一盒（一卦純清）；只變下卦一爻 = 同卦限內跳相鄰球殼。
- 分運與 R/r 無關。R = r 時：九運→中心、二三四運→面心（每點 4 卦）、六七八運→稜中點（每點 2 卦）、一運→頂點，共 27 位置，即 SPDF_CUBE.md 的 26 點加中心。
- 立體易粒子字典用的交錯疊法（外卦 二四上、內卦 初三五）下，每個運拆成 2 + 6 散在兩層球殼。大卦屬於上下疊法這張座標圖。

## 3. 羅盤先天圓圖

圓圖順序（從午起逆時針）：橫圖 63→32（乾…復）接 0→31（坤…姤），即二進位計數（初爻為最高位）在中間對折。

| 檢查 | 結果 |
|---|---|
| 相鄰兩卦差幾爻 | 1 爻 34 對、2 爻 16、3 爻 8、4 爻 4、5 爻 2 → 不是一筆畫（格雷碼要 64 對全為 1 爻） |
| 每 8 卦一段 | 下卦相同，段的方位就是下卦的先天八卦方位 |
| 段內順序 | 上卦依先天次序 乾兌離震巽坎艮坤 |
| 對面兩卦 | 全為錯卦（中心反演）；卦運相同、卦數合十 |
| 每段 | 八個卦運、八個卦數各出現一次 |
| 先天八卦圓本身 | 相鄰差 1、2、1、1、1、2、1、1 爻，也不是立方體上的一筆畫 |

每段 8 卦落在幾個卦限（λ = 2）：

| 座標圖 | 每段佔卦限數 | 相鄰兩卦是小方塊一條稜的次數 |
|---|---|---|
| 上下疊，上卦為大 | 8 | 2 |
| 上下疊，下卦為大 | 1 | 32 |
| 交錯疊（粒子字典） | 4 | 18 |

**結論**：圓圖 = 以下卦為大立方體、上卦為小立方體的兩層八叉樹，先走大卦限、再走卦限內的 8 點（Morton/Z 序），首尾對折以讓對面成錯卦。分區對應整齊，相鄰不保證只差一爻。若要一筆畫，要用格雷碼或希爾伯特式的走法，那不是傳統羅盤的排法。

## 4. 洛書編號 N 的結構

以下對 8 個值逐一驗算。三爻記為 (初, 二, 三)。

- **閉式**：N(r) = 1 + 2·r初 + r二 + 5·(r初 ⊕ r二 ⊕ r三)。
- **上元、下元 = 奇偶**：卦運 1～4 正好是上下卦不同爻數為偶數的 32 卦，也就是六爻陽數為偶數；6～9 為奇數。換個說法，上元／下元是 Q₃ 的二分圖著色。
- **三種「合」是一個克萊因四元群** H = {000, 001, 110, 111}（XOR 一個固定的三爻）：
  - ⊕111（乾）：合十，N + N′ = 10（1-9、2-8、3-7、4-6）
  - ⊕001（艮）：合生成，|N − N′| = 5（1-6、2-7、3-8、4-9，河圖生成數）
  - ⊕110（兌）：合五／合十五，N + N′ = 5 或 15（1-4、2-3、6-9、7-8）
- **同運八卦**是 Δ 的陪集，兩兩相差 2、4 或 6 爻（96、96、32 對），沒有相鄰的兩卦。(上, 下) ↦ 上⊕下 是圖同態 Q₆ → Q₃：變任何一爻都必定換運，而且換到 Q₃ 上相鄰的運（球殼差一層）。
- **N 打破三條爻軸的平等**：6、7、8 運互為爻位的排列，2、3、4 運也是，但號碼不同；H 也挑出了第三爻那條軸。這些是編號的約定，不是結構。

## 5. 與 SU(3) 字典的接口（評 2026-10-27 外部意見「64 → 8 → 6+2」；對方已撤回）

外部意見提議 Q₆ →δ Q₃ →D A₂ ∪ {0, 0}。這是集合上的合成，不是保結構的接口：

1. **疊法不同**：δ 用上下疊（初二三 對 四五上）；粒子字典的色用交錯疊的內卦（初三五）。
2. **記號衝突**：本 repo 的 `D` 是乾坤軸的轉動生成元（見 `QianKunAxis.lean`），不是 Q₃ 到根系的映射。
3. **投影給的是權，不是根**：八頂點沿乾坤軸投影是 3 ⊕ 3̄ 的六個權加兩個無色（長度平方 1/3）；六個根是兩個權的差（長度 1）。
4. **對稱不相容**：δ 的不變群是「上下同位一起翻」的 (Z₂)³；SU(3) 這一側認的是爻位排列（Weyl 群 S₃）和全翻（電荷共軛）。兩者交集只有 {不動, 全翻}。另外 N 本身打破 S₃（§4 最後一點）。
5. **XOR 不是權的加法**：w(u⊕v) = w(u) + w(v) − 2·w(u∧v)，只有兩卦沒有共同陽爻（或共同部分投影為零）時才是相加；64 個有序對裡成立 28 個。

**兩條線共同的不變量只有六爻奇偶**（§6）。球殼指標 w_H(上⊕下) 本身依賴上下疊這張座標圖；在交錯疊的字典裡，它只剩下奇偶這一個位元。

## 6. 上元／下元在第二版粒子字典裡是什麼（腳本：dagua_v2_parity.py）

原本的猜想是「上元／下元 = Spin(12) 的兩個手徵 = 左手、右手」。在第二版字典（RULES_V2.md）裡這個前提不成立：64 卦 = 16 個態 × 4 個外卦方向，16 個態全是 SO(10) 的同一個手徵（左手場和右手場的共軛），外卦是世代方向向量，不是三個佔據位元。所以字典裡沒有「按奇偶分左右手」這回事。

實際成立的是：

| 結果 | 說明 |
|---|---|
| 六爻陽數奇偶 = 弱1 位元 | 64 卦全部成立（因為 w1 = (c + w2) mod 2） |
| 上元（偶） | d_L、e_L、u^c、ν^c，電荷全部 ≤ 0，總和 −16 |
| 下元（奇） | u_L、ν_L、d^c、e^c，電荷全部 ≥ 0，總和 +16 |
| 質量配對（內卦取錯卦） | 全部跨元；每個狄拉克質量項都把上元的一個態接到下元的伙伴 |
| 變一個外卦爻 | 電荷變化恆為 ±1，必跨元 |
| 變一個內卦爻 | 電荷變化 ±2/3 或 ±4/3，必跨元 |
| 每個卦運（上下疊）的 8 卦 | 正好是該元的 8 個態各一次，外卦方向也各一次 |

最後一列是兩張座標圖互相橫截造成的：同運 (下 v, 上 v⊕r) 裡，交錯疊的內卦 (v初, v三, v二⊕r二) 和外卦 (v二, v初⊕r初, v三⊕r三) 都隨 v 一一對應。所以卦運除了「屬於哪一元」之外，不帶任何粒子資訊。

**結論**：字典和大卦的奇偶沒有矛盾；大卦能在字典裡留下的只有一個位元（弱1，相當於電荷 ≤ 0 或 ≥ 0 的分組）。沒有新的物理。

## 7. XOR 與共軛

- XOR 任何固定的卦都是對合（做兩次回原樣）。
- XOR 可交換，所以在 XOR 自己的群裡共軛 b·a·b⁻¹ = a，沒有內容。
- 八種翻法裡，只有 XOR 坤保持每一卦的陽爻數，只有 XOR 乾把 k 換成 3 − k（3 ↔ 3̄，色的電荷共軛）；其餘六種打亂分層。
- 在立方體對稱群裡，交換初二 · 翻初 · 交換初二 = 翻二：做共軛的是爻位交換，不是 XOR。
- 綜卦（六爻上下顛倒）不是任何 XOR。
